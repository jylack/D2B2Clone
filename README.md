# 기업협약 팀 프로젝트 
## 🧩 챕터 1 개발 내용 (담당: 조영락)

D2B2 프로젝트의 챕터 1 전체 개발을 맡아,  
NPC 상호작용부터 안전가이드, CSV 기반 로직, 신호등 시스템까지 구성했습니다.

---

### ✅ 개발 기간별 작업

#### 🔎 테스트 단계
- 팔 스윙 인식 및 이동 로직 구현
  - 한쪽 팔만 스윙해도 이동 가능
  - 스윙 범위, 중간중간 UI 표시
  - 머리 회전 상관없이 정면 유지 이동
    
#### 🛠 1차 개발
- **특수 구역 제작**: 안전라인, 위험지역, 횡단보도, 웨이포인트 등
- **특수 상황 처리**: NPC 동선, 안전가이드 유도, 신호등 조건부 정지
- **컨트롤러 조작**: 스틱 이동, 손 들기 애니메이션 조건 반영
- **최종 위치 저장 및 최근 웨이포인트 기록**

#### 🚧 2차 개발
- **챕터 1 통합 개발 마무리**
- **NPC 미션리스트 프리팹 개발**
- **CSV 로더 개발 및 적용**
- **안전가이드 시나리오 제작**
  - 안전선 대기
  - 신호등 정지
  - 보행 중 멈춤
  - 무단횡단 판별



---

### 💡 기술적 특징

- `Jira 태스크 기반 개발 및 단계별 완료`
- `CSV 데이터 기반` NPC/가이드 구성
- Unity 애니메이션/이벤트 + 로직 동기 처리
- Timeline로 안전가이드 시나리오 제작
